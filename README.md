# OpsFable website (GitHub Pages)

A responsive static site built with HTML, CSS and vanilla JavaScript. It is designed to publish on GitHub Pages at no hosting cost.

## Before publishing

1. In `index.html`, replace `mailto:REPLACE_WITH_YOUR_EMAIL` with your real business email address.
2. Review the brand name/domain/trademark status before investing in a custom domain.
3. Review all service claims and demo descriptions. Demo cards are explicitly labelled as concepts using sample data.

## Publish using GitHub Pages

1. Create or sign in to GitHub.
2. Create a public repository named `opsfable.github.io` if the username/organization is `opsfable`; otherwise create a repository named `opsfable-website`.
3. Upload `index.html`, `styles.css`, `script.js`, `favicon.svg`, and this README to the repository root.
4. For a project repository: open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. For a user/organization repository named `<username>.github.io`, GitHub Pages generally publishes from the root after the repository is created. Confirm Pages settings if needed.
6. Wait for the Pages deployment to complete. The project site URL is usually `https://<username>.github.io/opsfable-website/`; the user/organization site is `https://<username>.github.io/`.

## Contact form

The contact button currently uses a `mailto:` link placeholder. This is intentional because GitHub Pages is static and does not run a backend. Replace the placeholder with your business email before launch. Later, we can connect a free-tier form service or build a secure backend if needed.
